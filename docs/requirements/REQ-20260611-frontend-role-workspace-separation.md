# REQ-20260611 前端角色工作台分离

## 背景

当前前端虽然存在 `/`、`/teacher/reviews`、`/admin/operations` 等路由，但全局 `App.vue` 使用同一个侧栏壳承载学生、教师、管理员入口，并在同一导航区域暴露跨角色切换。用户反馈“管理员、学生、教师界面不分离”，这会削弱角色边界，也会让前端看起来像演示驾驶舱。

## 目标

- 学生、教师、管理员进入各自独立的工作台视觉壳。
- 全局入口应体现角色边界，而不是把三类用户混在同一个业务侧栏中。
- 不改变现有后端 API、DTO、数据库 schema 和认证合同。
- 保留已有学生、教师、管理员页面能力。

## 非目标

- 不拆分 `StudentDashboard.vue` 内部业务状态。
- 不新增角色权限后端逻辑。
- 不新增依赖。
- 不重做整站视觉系统。

## 验收要求

- `/` 显示学生工作台壳，只暴露学生学习相关导航和当前学生身份。
- `/teacher/reviews` 显示教师工作台壳，只暴露教师审核相关导航和教师身份。
- `/admin/operations`、`/admin/model-providers` 显示管理员工作台壳，只暴露管理员运维和模型配置相关导航。
- 跨角色入口可以作为清晰的顶部/全局角色入口存在，但不能混入某个角色的业务侧栏。
- 前端测试和构建通过。
