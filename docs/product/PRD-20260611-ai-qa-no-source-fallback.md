# AI QA 无资料降级回答 PRD

## 背景

当前学生端课程问答在 `/api/ai/qa` 下复用 RAG 查询结果。当 RAG 没有检索到可靠课程来源时，界面会展示“安全拒答 / ERROR”，这不符合目标体验：有课程资料时优先按 RAG 工作流回答；没有资料时，应退回到类似 ChatGPT Web 的普通问答工作流，而不是把普通问题直接视为失败。

## 目标

- 有可用课程来源时，继续返回基于课程资料的回答、引用和 traceId。
- 无可靠课程来源时，后端返回一个受控的通用 AI 回答占位策略，不再让学生端展示为错误。
- 前端明确区分“课程资料回答”和“无课程资料的通用回答”，避免伪造引用。
- 不改变纯 RAG 接口、RAG 评测、资源生成引用治理的 no-source 规则。

## 非目标

- 不接入新的大模型供应商。
- 不新增数据库表或迁移。
- 不实现 SSE 流式统一 QA。
- 不改变 `/api/rag/query` 的 no-source 拒答合同。

## 用户体验

学生提交课程问题后：

- 如果检索到课程来源，页面展示课程依据、引用、traceId 和安全摘要。
- 如果没有检索到课程来源，页面展示“通用回答”状态，说明本次未使用课程资料，并给出后端生成的通用解释。
- 页面不应把无来源降级显示为 `ERROR`。

## 验收标准

- `/api/ai/qa` 在 no-source RAG 结果下返回非拒答答案，并带有来源状态字段。
- no-source 降级响应的 `sources` 为空，且不伪造引用。
- 前端根据来源状态展示“通用回答”，不展示“安全拒答”。
- 现有纯 RAG no-source 测试继续保持拒答语义。
